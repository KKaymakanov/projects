# Проект 2: Банкомат с условие

## Описание
Програмата има начална сума пари в банкомата. Потребителят избира колко да изтегли, а банкоматът пита за причина. Тегленето се разрешава само ако причината е `спешно`.

## Технология
Използван е Python, защото е подходящ за кратки конзолни програми с вход от потребителя, проверки и условна логика. Няма нужда от външни зависимости.

## Стартиране
### Linux / macOS
Отвори терминал в главната папка `final_projects`, след това изпълни:

```bash
cd project_2_atm
python3 main.py
```

### Windows
Отвори Command Prompt или PowerShell в главната папка `final_projects`, след това изпълни:

```powershell
cd project_2_atm
python main.py
```

## Правило
Началната сума е `500 лв.`. Тегленето е успешно само ако:

- сумата е положителна;
- има достатъчно пари;
- причината е точно `спешно`.
