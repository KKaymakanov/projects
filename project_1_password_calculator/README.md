# Проект 1: Парола и калкулатор

## Описание
Потребителят има максимум 3 опита да въведе правилната парола. Ако паролата е вярна, програмата позволява изчисление с две цели числа и избрана операция.

## Технология
Използван е Python, защото задачата е малка конзолна програма и не изисква допълнителни библиотеки. Кодът е кратък, лесен за четене и лесен за стартиране.

## Стартиране
### Linux / macOS
Отвори терминал в главната папка `final_projects`, след това изпълни:

```bash
cd project_1_password_calculator
python3 main.py
```

### Windows
Отвори Command Prompt или PowerShell в главната папка `final_projects`, след това изпълни:

```powershell
cd project_1_password_calculator
python main.py
```

## Данни
Паролата в програмата е:

```text
1234
```

Поддържани операции: `+`, `-`, `*`, `/`.
