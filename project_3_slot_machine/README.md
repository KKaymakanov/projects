# Проект 3: Слот машина

## Описание
Потребителят зарежда 50 лв., за да играе. При всяко завъртане се генерират 3 случайни числа от 1 до 9. Ако трите числа са еднакви, потребителят печели.

## Технология
Използван е Python и стандартният модул `random`. Това е най-простото решение, защото задачата изисква само конзолен вход, цикъл, проверки и случайни числа.

## Стартиране
### Linux / macOS
Отвори терминал в главната папка `final_projects`, след това изпълни:

```bash
cd project_3_slot_machine
python3 main.py
```

### Windows
Отвори Command Prompt или PowerShell в главната папка `final_projects`, след това изпълни:

```powershell
cd project_3_slot_machine
python main.py
```

## Правила
- Начални пари: `50 лв.`
- Цена на опит: `10 лв.`
- Печалба при 3 еднакви числа: `100 лв.`
- След всеки неуспешен опит програмата пита дали потребителят иска да продължи.
